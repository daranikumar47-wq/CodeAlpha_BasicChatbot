# CodeAlpha_BasicChatbot
codeAlpha python Internship
Basic Chatbot Using Python
1. Project Description
The Basic Chatbot is a simple rule-based chatbot developed using Python. It communicates with users through text input and provides predefined responses based on user messages.
This project was developed as part of the CodeAlpha Python Internship.
2. Project Objectives

To understand basic Python programming.
To learn conditional statements.
To implement loops and functions.
To create a simple interactive chatbot.

3. Features

Greets the user with a welcome message.
Responds to "hello".
Answers "how are you".
Introduces itself when asked its name.
Ends the conversation when the user types "bye".
Provides default responses for unknown messages.

4. Technologies Used

Python
If-elif-else statements
Functions
While Loop
Strings
Input and Output

5. How to Run the Program

Install Python on your computer.
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run the following command:

python chatbot.py


Enter messages to interact with the chatbot.
Type bye to exit.
